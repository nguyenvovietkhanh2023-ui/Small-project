# Guess Game 

 - Guess Game là một trò chơi đoán số thông qua thông báo lớn hơn hoặc nhở hơn, viết bằng C++ và chạy trên console.

# Tính năng 

- UI game được thiết kế để hiển thị lên terminal một cách dễ nhìn 
- Bộ lựa chọn Menu 
- Điều chỉnh giới hạn số có thể random trong một màn chơi và có thể đặt lại mỗi màn 


## Cách chạy

Cần cài sẵn trình biên dịch g++. Mở terminal tại thư mục chứa file rồi chạy  

   # Cách chơi 

+ Bắt đầu với Menu chọn bao gồm : Play | Rule | Exit 
 ( chọn thông qua các con số và báo lỗi nếu không nhập đúng yêu cầu ) 
+ Lựa chọn số n ( là giới hạn random số để đoán trong màn chơi ) 
+ Cứ mỗi lần đoán sẽ cộng thêm số đoán để làm số điểm mỗi màn 
+ Kết thúc mỗi màn sẽ cho phép chơi tiếp hay không 


# Kiến thức : 
- Học được cách sử dung vòng lặp 
- Cách sử dụng hàm random có sẵn
