# Small-project

Repo lưu lại các bài tập và dự án nhỏ trong quá trình mình học C++ và làm web cơ bản.

## Danh sách dự án

| Dự án                                | Loại               | Mô tả                                                     |
|--------------------------------------|--------------------|-----------------------------------------------------------|
| [XO_game.cpp](XO_game.cpp)           | C++                | Game XO (Tic-Tac-Toe) chơi trên console                   |
| [MAZE](MAZE)                         | C++                | Game thoát mê cung                                        |
| [GUESS GAME .CPP](<GUESS GAME .CPP>) | C++                | Game đoán số                                              |
| [TAI XIU.cpp](TAI%20XIU.cpp)         | C++                | Game Tài Xỉu                                              |
| [EXPENSE MANGE](<EXPENSE MANGE>)     | C++                | Chương trình quản lý chi tiêu ( hoàn thiện ở mức cơ bản ) |
| [WEBSITE LEARN](<WEBSITE LEARN>)     | HTML/CSS/JS        | Website cá nhân ( đang hoàn thiện )                       |


## Cách chạy các chương trình C++

1. Cài trình biên dịch g++ (hoặc dùng Visual Studio / Code::Blocks).
2. Mở terminal tại thư mục chứa file, ví dụ:
        g++ XO_game.cpp -o xo_game ./xo_game
(Trên Windows chạy `xo_game.exe`.)

## Mục tiêu

- Luyện tư duy lập trình qua các game nhỏ.
- Làm quen với Git và GitHub để lưu trữ code.
